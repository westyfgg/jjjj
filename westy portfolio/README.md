# WESTY Portfolio

Це статичний сайт-портфоліо без додаткових залежностей або сервера:

- `index.html` — структура сторінки та український текст;
- `css/style.css` — оформлення, адаптивність та анімації;
- `js/main.js` — мобільне меню та поява блоків під час прокручування.

Файл `index.html` залишається в корені проєкту, щоб GitHub Pages автоматично
відкривав його як головну сторінку.

## Перегляд

Відкрийте `index.html` у браузері.

## Публікація через GitHub Pages

1. Створіть окремий GitHub-репозиторій і завантажте до нього весь вміст папки
   `westy portfolio`, зберігши структуру `index.html`, `css/` та `js/`.
2. У репозиторії відкрийте **Settings → Pages**.
3. У блоці **Build and deployment** виберіть **Deploy from a branch**.
4. Виберіть гілку `main`, папку `/(root)` і натисніть **Save**.
5. Після публікації відкрийте адресу, показану в налаштуваннях Pages.

Контакти, статистика, послуги та тексти редагуються в `index.html`. Для стилю
змініть `css/style.css`, а для поведінки сторінки — `js/main.js`.
