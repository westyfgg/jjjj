# WESTY Portfolio

Це статичний сайт-портфоліо без додаткових залежностей або сервера:

- `index.html` — структура сторінки та український текст;
- `css/style.css` — оформлення, адаптивність та анімації;
- `js/main.js` — мобільне меню та поява блоків під час прокручування.

Файл `index.html` залишається в корені проєкту, щоб GitHub Pages автоматично
відкривав його як головну сторінку.

## Перегляд

Відкрийте `index.html` у браузері.

## Публікація через GitHub Pages

1. Створіть GitHub-репозиторій, наприклад `westy-portfolio`.
2. Завантажте **весь вміст** цієї папки прямо в корінь репозиторію. У корені
   мають бути `index.html`, `css/`, `js/`, `.nojekyll` і `.github/`. Не
   завантажуйте лише ZIP і не кладіть ці файли всередину додаткової вкладеної
   папки.
3. Переконайтеся, що головна гілка називається `main`, і натисніть **Commit
   changes**.
4. У репозиторії відкрийте **Settings → Pages**. У розділі **Build and
   deployment** виберіть джерело **GitHub Actions**.
5. Відкрийте **Actions** і дочекайтеся успішного завершення **Deploy portfolio
   to GitHub Pages**. Цей проєкт містить workflow
   `.github/workflows/pages.yml`, який публікує сайт під час кожного оновлення
   гілки `main`.
6. URL сайту з’явиться в **Settings → Pages** або в результаті workflow.

Для репозиторію `westy-portfolio` адреса зазвичай має вигляд
`https://<ім’я-акаунта>.github.io/westy-portfolio/`. Кожен репозиторій має
власні налаштування GitHub Pages; 404 означає, що сторінку ще не опубліковано,
вибрано не те джерело/гілку або файли опинилися не в корені репозиторію.

Контакти, статистика, послуги та тексти редагуються в `index.html`. Для стилю
змініть `css/style.css`, а для поведінки сторінки — `js/main.js`.
